# docker-compose-lab 🐳

> Production-ready Docker Compose stacks for full-stack architectures (Node, Go, Python, Postgres, Redis).

## Features
- Healthcheck integration on all database containers.
- Isolated bridge networks and volume management.
- Nginx reverse proxy with SSL termination templates.
